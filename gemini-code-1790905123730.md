# Role & Purpose
You are an expert Principal Frontend Engineer and Data Architect specializing in Industrial Timber & Lumber ERP/BI solutions (similar to Epicor LumberTrack and Phocas Analytics). 

Your task is to build a high-performance, clean, and elegant React single-page application (SPA) named **"TimberPulse Analytics & ERP Suite"**. The application serves as a unified Operations & Financial Intelligence Platform for a group of 5 interconnected operating entities (EINs) in the timber and industrial wood products manufacturing space.

# Key Architectural & Technical Requirements

### 1. Framework & UI Stack
* **React 18+** with **Tailwind CSS** for styling.
* **Icons:** `lucide-react` icons throughout.
* **Charts:** `recharts` for rich analytics, bar charts, line graphs, pie charts, and gauges.
* **Component Styling:** Clean, modern corporate UI with a high-contrast dark/light mode toggle. Use industrial wood-inspired accent palettes (deep forest green `#1b4332`, warm amber/timber `#d97706`, and clean slate grey `#0f172a`).

### 2. Embedded In-Browser Web LLM Chat Agent ("Tim")
* Implement a natural language query interface featuring **Tim (Timber Intelligence Manager)**.
* **LLM Engine:** Use `@mlc-ai/web-llm` or an in-browser Web-LLM client (with a simulated fallback/mock parser if Web-LLM model weights are loading or unavailable).
* **NL-to-SQL Workflow:**
  1. User asks a natural language question (e.g., *"Show me YTD labor cost vs revenue across all EINs"* or *"Which plant had the highest piece-rate yield this week?"*).
  2. Tim converts the natural language input into a structured SQL query target against the in-memory mock JSON database.
  3. Tim executes the query locally, returning:
     - Clear text/bullet summary of insights.
     - Formatted interactive data table.
     - **Dynamic Visualization Toggle:** Buttons to render the result directly as a Bar Chart, Line Graph, or Data Table inside the chat bubble.

### 3. Application Layout & Navigation Structure
* **Persistent Top Header:**
  * Global search bar.
  * Multi-EIN Selector Dropdown (`All Entities (Consolidated)` vs individual EINs: IWP, ECL, Box & Crate, KRFT, Welcome Logistics)[cite: 1, 5].
  * System Health indicator (Status: Active / API Sync Status)[cite: 5].
  * Active User Profile Menu (`Bryan Cone / CFO` or `Plant Manager`)[cite: 1, 5].
  * Dark/Light Theme toggle.
* **Persistent Footer:**
  * System metadata, data freshness timestamp, copyright, and active ERP connection status (e.g., `Epicor LumberTrack: Connected via REST API` | `GL: GP Migration Target 1/1/27`)[cite: 1, 3, 5].
* **Sidebar / Main Navigation Tabs:**
  1. 📊 **Unified Executive Dashboard** (Consolidated Ops & Financials)[cite: 5]
  2. 🏭 **Plant Ops & Cut Yield Analytics** (Board Feet, Piece-Rate, Lumber Recovery Factor - LRF)[cite: 2, 5]
  3. 💰 **Financial & Labor Margin Analysis** (Gross Revenue, Overtime, Piece-rate incentives, Freight Costs)[cite: 5]
  4. 🚚 **Logistics & Scalehouse Hub** (Yard decks, truck turnaround, scale tickets, BOL matching)[cite: 2]
  5. 💬 **Chat with Tim (AI Data Agent)** (Natural Language Query Console)[cite: 2, 5]
